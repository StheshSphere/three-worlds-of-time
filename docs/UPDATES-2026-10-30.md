# Updated release — 30 October 2026

The submitted 24 October LAMP game is the runtime base. The supplied GitHub source provides the development files and the Ancient Ruins archway correction.

## Included fixes

- Ancient Ruins walls stop at the outside edges of the arch piers. The overlapping faces that caused flickering are removed.
- The title menu hides its scrollbar on smaller displays and uses more compact spacing in shorter windows. Scrolling remains available when needed, including when a control receives keyboard focus.
- The Level 1 Sun Gate keeps its full collision barrier throughout its 2.6-second opening animation. Sprinting and jumping cannot pass through it early. The barrier is removed only when the animation reaches its final position. Gate dialogue and the next courtyard entry trigger also wait for completion.
- Restart this era closes the gate again and restores its collision barrier.
- Browser cache versions point to the updated files. The release builder now resolves module URLs containing cache query strings correctly.

All other submitted runtime files are preserved. The tablet combinations, journal reset, save/continue, optional hint system, dialogue controls, and Back to statistics feature remain included.

## Validation

139 automated checks passed across the integration, interaction, tablet, jump, dialogue and audio suites. The tablet suite includes 4,320 real level interaction cases covering generated codes, tablet assignments and collection orders.

Chromium rendered the actual game without JavaScript, shader or HTTP errors. Title layout checks passed at 1366×768, 1280×720, 1024×600, 800×600, 690×700, 640×480, 360×640 and 320×400. Scrollbars remain hidden and overflowing content can still scroll. Gate collision and passage checks passed in both first-person and third-person views.

The separate LAMP archive was extracted and served from a nested course/game folder. It loaded without errors and retained the closed, opening and fully open gate behavior. All 222 files from the submitted runtime are present. ZIP integrity and identical runtime bytes between the LAMP and GitHub packages were checked.

The checks use scripted interactions and puzzle shortcuts; they are not a complete manual traversal of every level.

## Which ZIP to use

**LAMP:** submit `Three_Worlds_of_Time_UPDATED_LAMP_2026-10-30.zip`. Its root contains `index.html`, `credits.html`, `assets/`, `libs/`, `licenses/` and `src/`. It requires no package installation or build on the server.

**GitHub:** extract `Three_Worlds_of_Time_UPDATED_GitHub_2026-10-30.zip`. Copy the contents of its `three-worlds-of-time` folder into your existing local repository and replace matching files. Keep the repository's existing `.git` folder. Commit and push the updated files as usual.

To check the source locally, run `npm start` or `python -m http.server 8000` inside the project folder, then open `http://localhost:8000`.
